y-cm: Modular CodeMirror Web Components

A beautiful, composable, and extensible editor built with web components, Atomico, and Tailwind CSS. Add or remove features by simply nesting extension tags inside <y-cm>.

Try editing the code below. Extensions are enabled via child tags.

How it works

  • <y-cm> is the main editor container.
  • Each <y-cm-*> child adds a feature or language extension.
  • Mix and match extensions for your use case.
  • All components are styled with Tailwind and use Lucide icons for a modern look.
